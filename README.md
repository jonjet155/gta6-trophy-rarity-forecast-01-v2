Earners/players decomposition forecaster for GTA VI trophy rarity. Models tracked players N(t) and earners E_i(t) separately in logit space with saturating curves, tier-pooled shrinkage, and dilution-aware priors for launch-week refreshes. Beats flat and trend baselines on practice cases.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
